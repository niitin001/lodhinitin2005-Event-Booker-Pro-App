# 🎉 Event Booker Pro

A modern Full-Stack Event Booking Platform that connects customers with professional event service providers such as Makeup Artists, Photographers, Wedding Planners, Caterers, DJs, and Decorators.

## 🚀 Live Demo

🔗 Live Website: Deployment pending (GitHub upgrade branch ready)

# ⚙ Installation

## Clone Repository

```bash
git clone https://github.com/lodhinitin2005/lodhinitin2005-Event-Booker-Pro-App.git
```

## Go to Project Folder

```bash
cd Event-Booker-Pro-App
```

## Install Dependencies

```bash
npm install
```

## Start Development Server

```bash
npm run dev
```
